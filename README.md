# 虛源靈流 V.O.F.

一個可直接在瀏覽器執行的靜態網站，提供「見頻、讚頻、歸靈、合靈」四筆法的本機引導。

## 使用方式

1. 下載或複製本專案。
2. 直接以現代瀏覽器開啟 `index.html`，不需要安裝 Node.js、套件或建置工具。
3. 按下「開始四筆法」，完成四個步驟；完成紀錄只會儲存在目前瀏覽器的 `localStorage`。

## 網站功能

- 單檔、離線可開啟，不依賴 Tailwind CDN 或其他外部資源
- 可操作的四筆法逐步引導
- 白皮書摘要視窗
- 最多保留 20 筆本機練習紀錄，並可自行清除
- 行動裝置版面支援與基本無障礙標記
