# 虛源靈流 V.O.F.｜課程網站

本專案為可直接開啟的單頁靜態網站，介紹虛源靈流與「虛源五階」課程。

## 網站架構

- 品牌定位、源流與發展
- 創始人介紹版位（不虛構未提供的資料）
- 虛源五階課程、適合對象與實操設計
- 教學情境案例與 FAQ
- 四筆法短引導
- 本機報名意向產生器

## 上線前需由主辦方補齊

1. 創始人的真實姓名、照片授權、簡歷與方法發展里程碑
2. 課程期別、日期、時數、費用、地點／線上方式、人數與退款規則
3. 正式課務信箱、報名系統或客服連結
4. 使用者資料蒐集與隱私政策

目前的報名表單不會將資料傳送至伺服器，只會產生可複製的意向內容。設定正式接收端點前，請勿宣稱已完成報名。

> 本站僅供教育與自我觀察，不提供醫療、心理治療、危機介入或療效承諾。
